# Benchmark B: audit API performance (baseline)

Closed: constant virtual users, no think time; each level runs a discarded warm-up then a measured phase. Fixed 20-slot cycle per virtual user: dashboard 30%, audit history 25%, audit detail 20%, audit lines 10%, audit creation 15%. Production API image (NODE_ENV=production, Secure cookies) and PostgreSQL 17.6 in an isolated compose project; rate limits raised. Load generator, API and database run on the same workstation.
