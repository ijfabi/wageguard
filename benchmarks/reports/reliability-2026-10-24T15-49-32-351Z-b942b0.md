# Benchmark E: reliability and recovery (fail-fast-503)

10 clients on the host submit audits back to back against the production API image. Same Idempotency-Key on every attempt; retry network errors and 5xx; backoff 250 ms doubling to 2 s; give up after 60 s. Each scenario runs 10 s of normal load, injects the fault, then continues for 30 s. Integrity is checked in SQL afterwards (cumulative across scenarios).

## Duplicate submissions

| Same key, 20 sequential retries  | 20       | 1       | 19       | 1                           | 1             |

The same key with a different request body returned HTTP 422.

## Failure scenarios

Injection: API crash: `docker exec wageguard-bench-api-1 sh -c "kill -9 $(pidof node)" (the container exits; restart policy on-failure restarts it)`. Database outage: `docker stop wageguard-bench-postgres-1; wait 10 s; docker start wageguard-bench-postgres-1`.
