# Security policy

WageGuard is a portfolio project under active development and is not deployed with real user data.

If you find a vulnerability, please do not open a public issue. Contact the maintainer privately through the contact details on their GitHub profile, and include reproduction steps.

The threat model and the controls in place are described in [docs/security.md](docs/security.md). Never submit real payslips or personal employment data to any WageGuard instance or issue tracker.
